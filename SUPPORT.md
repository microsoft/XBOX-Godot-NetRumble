# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Before filing, check
[Known issues](docs/known-issues.md), which lists the bugs we already know about, and
[Troubleshooting](docs/troubleshooting.md): it covers the failures that come up most often,
including the HRESULTs that surface at GDExtension load, export and sign-in. Please also search
the existing issues to avoid duplicates. For new issues, file your bug or feature request as a
new issue.

When reporting a problem, the following make it far easier to act on:

- Which platform you were running on (Godot editor on desktop, an exported PC build, or console)
- Whether you were signed in to an XBOX account, running offline, or using a `--pf-user` test client
- Your Godot version, and whether you were using a Middleware console fork
- The relevant output from the Godot Output panel or the console log
- For a multiplayer issue, whether both peers saw it and what each one showed

For help and questions about using this project, please open a Discussion or an issue with the
`question` label.

## Related projects

The GDK and PlayFab Godot addons this sample depends on live in
[microsoft/XBOX-Godot-Sample](https://github.com/microsoft/XBOX-Godot-Sample). Issues with the
addons themselves, such as a missing binding or a crash inside an addon call, belong there rather
than here.
